# 📊 Etapa IV: Consultas y Casos de Uso

Esta carpeta contiene la documentación y evaluación de los casos de uso comerciales y gerenciales desarrollados sobre la base de datos

### Contenido
* **Consigna 1 (Factura / Comprobante):** Consulta consolidada de encabezado y detalle con subtotales por renglón y cálculo de total acumulado dinámico mediante funciones de ventana (`SUM(...) OVER PARTITION BY`).
* **Consigna 2 (Reportes Agregados):** Análisis multidimensional por período (vendedor, categoría, forma de pago y producto) utilizando `GROUP BY`, `SUM`, `COUNT` y `AVG`
* **Consigna 3 (Consulta de Negocio Avanzada):** Identificación de clientes VIP/mayoristas mediante `JOIN` multitabla, filtrado en `HAVING` y subconsultas derivadas sobre el gasto promedio general
* **Ajustes y Consistencia:** Documentación del reajuste de datos de prueba para asegurar coincidencia numérica en el total recaudado del período
