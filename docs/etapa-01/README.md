# 📌 Etapa I: Requerimientos y Dominio del Negocio

En esta carpeta se encuentra la documentación fundacional del sistema de gestión para el **Frigorífico Cárnico y Carnicería Industrial** (Grupo 36).

### Contenido
* **Descripción del Caso y Alcance:** Definición del modelo operativo para los canales minorista (atención de mostrador) y mayorista (restaurantes, supermercados y carnicerías).
* **Reglas de Negocio (RN):** Especificación explícita de las reglas operativas principales, incluyendo el control estricto de inventario, registro y padrón de clientes, trazabilidad e histórico de precios en detalles de venta (evitando alteraciones retroactivas), restricción de unidades de medida (kg/unidades) y modalidades de cobro habilitadas.
