# 📐 Etapa II: Modelado Conceptual y Lógico

En esta sección se detalla el diseño conceptual y relacional de la base de datos `FrigorificoDB`.

### Contenido
* **Diagrama Entidad-Relación (DER):** Modelado en notación Peter Chen especificando entidades, atributos, relaciones y cardinalidades.
* **Transformación al Modelo Relacional:** Mapeo formal indicando Claves Primarias (PK) y Claves Foráneas (FK).
* **Proceso de Normalización:** Documentación paso a paso de la evolución del modelo desde la vista no normalizada (**UNF**) pasando por **1FN**, **2FN** hasta alcanzar la **Tercera Forma Normal (3FN)**.
